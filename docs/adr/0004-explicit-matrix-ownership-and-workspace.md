# 所有行列とビューを分け、計算用メモリを事前準備する

固定・動的サイズの所有行列と非所有ビューを分け、既定配置はrow-majorとする。Eigenの既定column-majorへの一致より、参照利用先の配列化と将来のWASM境界を優先し、外部の別配置はstride付きビューで扱う。速度の優位は実測で判断する。動的行列の確保と深いコピーを明示し、計算の出力とworkspaceを事前準備して再利用することで、PCと組み込みの共通APIから無確保計算を選べるようにする。

[行列の所有権・配置・メモリ予算を決める](https://github.com/takuto-NA/kibo-linalg/issues/4)。
