# コアは例外・RTTIを要求せず、ヒープ利用を任意とする

ポータブルな数値計算コアは、例外とRTTIを有効にしなくても使える契約とする。PCの動的行列ではヒープ確保を許し、呼出し側が渡すメモリで動く構成も提供する。PCと組み込みで別々の必須APIを育てる選択より、共通のコアを各環境の制約に合わせて使えることを優先する。失敗通知、所有権、workspaceの契約は[API文書](../api.md)に定める。周辺アプリケーションで例外・RTTIを使うことは妨げない。

[最低C++版とターゲットごとの動作保証を決める](https://github.com/takuto-NA/kibo-linalg/issues/3)。
