# 動的所有・LLT・QRのPC検証

対象: GitHubの動的行列・LLT・列pivot付きQRの実装チケット。
Windows x64、MSVC19.44.35222.0、toolset14.44.35207、CMake3.30.5。

Debugで公開APIを実行し、次を確認した。

- move-only owner、create/clone/resizeの失敗注入、元のshape/値保持、共通範囲保持、zero/overflow、資源の二重解放・リークなし。
- 同じ動的ownerテストを例外/RTTI無効consumerでもpass。
- LLT共通2×2解[1/11,7/11]、既知SPD解[1,-2,3]、非対称/非SPD/Inf、pivot診断、容量1 byte不足、workspace misalignment。
- LLT途中overflowで解出力保持、既定factorはinvalid_factor。
- QRの既知inconsistent最小二乗、consistent、正方系の列交換と逆permutation、重複列のrank不足、閾値の上/下、1e-150/1e150の尺度変更、容量不足とNaN。
- QR queryはn=2/8/32/128/512、m=n/4nで成功。
- 無例外/RTTI consumerでLLT/QR factor+solveを実行。
- 校正済みMSVC Debug CRT probeで、事前準備した基本演算・LLT/QR factor+solve各100回の確保回数0。
- 共通2×2の数値領域は4 KiB以内（compile-time assertion）。

レビュー: Standards 規約違反0、共通CHECKマクロの重複1件をテストヘッダに集約。
Spec 指摘0。factor handleとdiagnosticsの借用領域の寿命を文書化した。
全テストのDebug/Release、install後利用、Linux等の保証は環境別チケットで検証する。
