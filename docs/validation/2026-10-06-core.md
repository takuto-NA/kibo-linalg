# 固定行列・ビューのPC検証

対象: [PCで固定行列と外部ビューの2×2計算を実行する](https://github.com/takuto-NA/kibo-linalg/issues/10)。
Windows x64、MSVC19.44.35222.0、toolset14.44.35207、SDK10.0.26100.0、CMake3.30.5。

- Debug公開APIテスト: pass。2×2 Ab=[6,7]、長方形の積、column-major/padding/transpose/submatrix、空行列、NaN/Inf、shape/layout/capacity/overflowを確認。
- 2ノルム: [3e200,4e200]=>5e200、[3e-200,4e-200]=>5e-200を相対1e-12以内で確認。
- 無例外/RTTI consumer: pass。C++20 concepts/spanとコンパイル時macroを確認。
- MSVC Debug CRT hookをmallocで校正し、事前準備した基本演算を100回実行: allocations=0。
- 独立レビュー: Standards 0件、Spec 0件。基準commit745b402b755acddc6d1858bcb86e150dccf4ff8fからの第一実装差分を対象。

再現コマンドは `docs/api.md`。CRT probeはこの構成での実測であり、Linux/WASM/ESP32での実行証拠は後続の受入対象。
Windows子プロセスにPATH/Pathが重複していたため、ビルド用環境だけ正規化した。常設環境は変更していない。
